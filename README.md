# 🚀 اسکریپت NexusNet

یک ابزار ساده، سریع و کاربردی برای مدیریت و راه‌اندازی چندین نود Tor با قابلیت انتخاب کشور Exit Node.

---

## 📋 پیش‌نیازهای سیستم

برای تجربه بهترین عملکرد و پایداری، استفاده از مشخصات زیر برای سرور پیشنهاد می‌شود:

* لوکیشن سرور: ترجیحاً آلمان 🇩🇪
* پردازنده (CPU): حداقل ۲ هسته
* حافظه رم (RAM): حداقل ۴ گیگابایت

> 💡 نکته مهم درباره پینگ:  
> کیفیت ارتباط و پینگ نهایی ارتباط مستقیمی با اینترنت کاربر و مسیر شبکه Tor دارد. هرچقدر کیفیت اینترنت کاربر با سرور شما سازگاری بهتری داشته باشد، پینگ پایین‌تر و اتصال پایدارتر خواهد بود.

---

🛠 راهنمای نصب
برای نصب اسکریپت، کافیست با دسترسی روت (Root) وارد ترمینال سرور خود شده و دستور زیر را اجرا کنید:
```bash
sudo bash -c "$(curl -sL "https://raw.githubusercontent.com/SiNaKeEn/NexusNet/Node/install.sh")"
```




---

## 🔄 نحوه اجرای مجدد منو

در صورتی که مراحل نصب به پایان رسید یا از منوی برنامه خارج شدید، نیازی به اجرای مجدد دستور نصب نیست. برای دسترسی دوباره به منوی مدیریت ابزار، کافیست کلمه زیر را در ترمینال تایپ و اینتر کنید:

```bash
nexusnet
```
