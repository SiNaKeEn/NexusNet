# 🚀 اسکریپت NexusNet

ابزار مدیریت چند نود **Tor Exit** روی یک سرور — با انتخاب کشور خروجی، اتصال به پنل‌های **3X-UI** و **پاسارگاد**، و منوی فارسی/انگلیسی ساده.

**نسخه فعلی: v1.16**

---

## 📋 پیش‌نیاز سرور

| مورد | پیشنهاد |
|------|---------|
| لوکیشن | ترجیحاً آلمان 🇩🇪 یا هلند 🇳🇱 |
| CPU | حداقل ۲ هسته |
| RAM | حداقل ۴ گیگابایت |
| سیستم‌عامل | Ubuntu / Debian |
| دسترسی | Root (`sudo`) |

### درباره پینگ
پینگ نهایی به اینترنت کاربر و مسیر شبکه Tor بستگی دارد. هرچه مسیر شبکه کاربر با سرور سازگارتر باشد، اتصال پایدارتر و تأخیر کمتر است.

> **نکته درباره IP تور:** در کشورهایی که Exit Node کم دارند (مثل امارات)، ممکن است همیشه یک IP ثابت ببینید. این محدودیت شبکه Tor است، نه باگ اسکریپت. از نسخه **1.13** با هر بار Restart، درخواست مدار جدید (`NEWNYM`) ارسال می‌شود تا در صورت وجود Exit دیگر، IP عوض شود.

## 🛠 نصب

با دسترسی Root در ترمینال:

```bash
curl -sL "https://raw.githubusercontent.com/SiNaKeEn/NexusNet/Multi-Node/install.sh" -o /tmp/install.sh && sudo bash /tmp/install.sh
```

> اگر خطای `Argument list too long` دیدید، حتماً از دستور بالا استفاده کنید (اول دانلود، بعد اجرا). از `bash -c "$(curl ...)"` برای این فایل استفاده نکنید.

## 🔄 اجرای مجدد منو

### حذف نود و پنل
با حذف نود از گزینه ۷، علاوه بر سرویس محلی، تنظیمات مربوط در **3X-UI** و **پاسارگاد** (Core) هم در صورت امکان پاک می‌شود. برای پاسارگاد یک‌بار از Panel Tools لاگین کنید تا اطلاعات ذخیره شود.

### بکاپ / بازگردانی
- **بکاپ:** لیست نودها و پورت‌ها در `/root/nexusnet_backup.txt`
- **بازگردانی:** نودهای موجود در فایل بکاپ که روی سرور نیستند دوباره ساخته می‌شوند
