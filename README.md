## 📋 پیش‌نیازهای سیستم

برای تجربه عملکرد بهتر و پایداری مناسب، استفاده از مشخصات زیر برای سرور پیشنهاد می‌شود:

- **لوکیشن سرور:** ترجیحاً آلمان 🇩🇪
- **پردازنده (CPU):** حداقل ۲ هسته
- **حافظه رم (RAM):** حداقل ۴ گیگابایت
- **سیستم‌عامل:** Linux
- **دسترسی:** Root / Sudo

> 💡 **نکته مهم درباره پینگ:** کیفیت ارتباط و پینگ نهایی، به عوامل مختلفی از جمله کیفیت اینترنت کاربر، مسیر ارتباطی و موقعیت سرور بستگی دارد. مشخصات سرور به‌تنهایی تضمین‌کننده پینگ مشخصی نیست.
